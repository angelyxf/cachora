# Cachora beta privacy

Effective: 2026-11-06.

Cachora scans supported cache locations only after you start a scan. It stores scan results in memory and keeps recovery records, original paths and retained copies on your Mac. Application preferences and any diagnostic logs are local. Recovery copies remain until you explicitly restore or permanently delete them.

The beta has no account, payment system, advertising, analytics SDK, automatic crash upload or automatic cleanup. File names, file contents and scan results are not uploaded by the beta application.

The **Check for Updates** button sends a request to the GitHub Releases API for this project's repository. GitHub receives normal connection information, including your IP address. The app does not include local paths or scan results in that request. Opening a project, release or feedback link uses your browser and the destination's own privacy policy.

When submitting an issue, review screenshots and logs yourself. Replace private paths with examples and omit documents, credentials and recovery copies. Feedback is sent only when you choose to submit it.

Recovery is a local holding area, not a separate backup. Permanent deletion removes the retained copy and cannot be undone through Cachora. Uninstalling or manually deleting the recovery folder can also remove your ability to restore it.

For questions, use the project's GitHub Issues page. There is no paid product or refund promise in this beta.
