# Cachora privacy

Effective: 2026-11-09.

Cachora reads local storage capacity and the installed application list for its overview and application tools. You can request a scan or opt into scheduled scans while Cachora is open. Scan results, original paths, retained copies, preferences and diagnostic logs stay on your Mac. Recovery copies remain until you restore or permanently delete them.

The application has no account, payment system, advertising, analytics SDK, automatic crash upload or automatic cleanup. File names, file contents and scan results are not uploaded by the application.

The **Check for Updates** button sends a request to the GitHub Releases API for this project's repository. GitHub receives normal connection information, including your IP address. The application update tool uses Homebrew and its configured sources when you request a check or update. Opening a project, release or feedback link uses your browser and the destination's own privacy policy.

When submitting an issue, review screenshots and logs yourself. Replace private paths with examples and omit documents, credentials and recovery copies. Feedback is sent only when you choose to submit it.

Recovery is a local holding area, not a separate backup. Permanent deletion removes the retained copy and cannot be undone through Cachora. Uninstalling or manually deleting the recovery folder can also remove your ability to restore it.

For questions, use the project's GitHub Issues page. There is no paid product or refund promise in this version.
